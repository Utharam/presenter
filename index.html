How to use Presenter

  1. 1Make or add a deck. Paste, choose, or drag an HTML file anywhere on the page.
  2. 2Present. Click a Recent decks row. One screen defaults to Present without notes; extended displays offer speaker view. The caret opens all three modes.
  3. 3Move. ← → or Space; Home End jump; F fullscreen.
  4. 4Notes. Edit per slide from Notes in a deck row. N toggles notes in Rehearse; S opens speaker view or the Rehearse console.
  5. 5Zoom & pan. Use − + in the status bar; hold H + arrow keys, or Ctrl/Cmd and drag, to pan while zoomed.

Speaker notes

Notes are optional author notes, one per slide. They stay hidden from the audience and appear only in Rehearse or speaker view. Build them with the AI prompt, edit them per slide from the library, and choose at presentation whether to use them.
