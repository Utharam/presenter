How to use Presenter

  1. 1Drop a deck. Paste, choose, or drag an HTML file anywhere on the page.
  2. 2Present. Click a Recent decks row to open it full-screen.
  3. 3Move. ← → or Space; Home End jump; F fullscreen.
  4. 4Notes & help. N notes; ? all shortcuts; Esc closes notes, then exits.
  5. 5Zoom & pan. Use − + in the status bar; hold Ctrl/Cmd and drag to pan while zoomed.
